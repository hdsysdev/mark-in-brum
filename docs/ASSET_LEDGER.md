# Asset Ledger

Canonical machine-readable ledger: `docs/asset_ledger.json` (schema v1).
This document describes the schema and the licensing policy. Every
third-party asset used at runtime MUST appear in the JSON ledger with a
verified archive hash; `tools/assets/validate_asset_ledger.py` fails the
build otherwise.

## Schema (per asset entry)

| Field | Meaning |
|---|---|
| `id` | Stable slug, e.g. `kenney_city_kit_roads` |
| `role` | What it is used for in the game |
| `source_url` | Exact page or file the archive came from |
| `author` | Creator/author credit |
| `license` | SPDX-ish identifier (`CC0-1.0`, `CC-BY-4.0`, `ODbL-1.0`, ...) |
| `archive` | File name under `art_source/third_party_archives/` |
| `archive_sha256` | SHA-256 of the original archive, as downloaded |
| `downloaded_on` | ISO date of download |
| `modifications` | Free-text list of transforms applied before runtime use |
| `runtime_outputs` | Paths under `assets/` produced from this source |
| `status` | `pending` (planned, not downloaded) or `integrated` |

## Policy

1. **CC0-first.** Prefer CC0 (Quaternius, Kenney, Poly Haven). CC-BY only
   when CC0 is unavailable and the exact author is recorded.
2. **No runtime CDN.** Every runtime asset is a local file. No scene may
   load a remote URL.
3. **Hash every archive.** The SHA-256 is recorded at download time and
   re-checked by the validator before any processing.
4. **License parity check.** If a download page's stated license disagrees
   with the archive contents, the asset is rejected and removed from the
   ledger.
5. **OSM (ODbL).** Map data derived from OpenStreetMap is attributed
   in-game and in `ATTRIBUTION.md`; the pinned extract is kept in
   `art_source/osm/`.
6. **Wikimedia Commons.** Any Commons image used as a texture must have its
   file-page license recorded per file; Commons images used only as
   reference need no redistribution license.
